# Client Financial Dashboard 📊

[![Node.js CI](https://github.com/kiltro-dev/client-financial-dashboard/actions/workflows/node.js.yml/badge.svg)](https://github.com/kiltro-dev/client-financial-dashboard/actions/workflows/node.js.yml)

A comprehensive financial dashboard built with React, TypeScript, and Vite.

## Tech Stack
- **Frontend:** React + TypeScript
- **Styling:** CSS / Theme Provider
- **Build Tool:** Vite

## Quick Start
```bash
npm ci
npm run dev
```

## Features
- Interactive financial charts
- Clean, responsive UI
- Strongly typed with TypeScript
